Por qué existe

No todo archivo necesita una cuenta para viajar

A veces solo hace falta pasar un archivo puntual: una foto, un PDF, un build para probar. Subirlo a un servicio, crear cuenta, y después acordarte de borrarlo es fricción que no aporta nada.

⚡

Cero fricción

Sin crear cuenta, sin login, sin tarjeta. Un comando y tenés un link listo para compartir.

📶

Sin conexión previa

El receptor no necesita estar conectado en simultáneo — abre el link o escanea el QR cuando quiera, es HTTP normal.

🧹

Se limpia solo

Nada que recordar borrar. Pasada la hora, Cloudflare elimina la cuenta temporal y el archivo con ella.

Funcionalidades

Lo justo para pasar un archivo

Cada archivo vive en su propio Durable Object, guardado en chunks dentro de su SQLite — sin R2, sin WebSocket.

📤

Subida drag & drop

Arrastrá el archivo o elegilo desde el explorador, con barra de progreso.

📱

QR en el navegador

El código QR se genera del lado del cliente, sin backend externo de por medio.

⬇️

Descarga con un click

El link abre una página con nombre, tamaño y un botón de descarga — nada de instalar nada.

✅

Verificado byte a byte

Probado con archivos reales de hasta 18MB, hash SHA-256 idéntico entre lo subido y lo descargado.

📏

Hasta 20MB

Límite pensado para no forzar la memoria del Worker al reconstruir el archivo completo.

📱

Mobile-first

La página de descarga se ve bien en cualquier celular, ideal para abrir desde la cámara.

Cómo funciona

De cero a QR en menos de un minuto

Cloná el repo

No hace falta tener cuenta de Cloudflare ni estar logueado.

git clone https://github.com/MauricioPerera/wrangler-ephemeral-airdrop.git cd wrangler-ephemeral-airdrop && npm install

Desplegá con --temporary

Wrangler crea una cuenta desechable, despliega el Worker y te da la URL pública.

npx wrangler deploy --temporary

Subí y compartí el QR

Arrastrá el archivo a la página, copiá el link o mostrá el QR. La otra persona lo descarga cuando quiera.

¿Te gustó? Quedátelo

Wrangler también te da una claim URL. Abrila y logueate antes de que venza la hora y el Worker pasa a tu cuenta real, para siempre. Si no hacés nada, se borra solo.
